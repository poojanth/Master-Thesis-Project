# Master-Thesis-Project
Desktop-VR based neuroscience experiment with Hardware-Software Integration for MEG/EEG Memory Study

## Overview
This project involved the development of a custom desktop-based virtual reality environment in Unity for a neuroscience study investigating how active movement and visual optic flow influence memory performance and cortical ripple-band activity.

The experiment was designed to study memory under controlled movement-related conditions while maintaining compatibility with simultaneous MEG and EEG recordings. A 2×2 experimental design was implemented, combining two main factors:

- Optic flow: moving visual environment vs. static screen
- Movement condition: active locomotion vs. passive replay

Participants completed memory encoding and retrieval tasks while behavioral responses and neurophysiological recordings were synchronized for later analysis.

## Contribution
I developed and implemented the Unity-based experimental framework, including the virtual environment, task logic, event handling, behavioral response logging, and integration of external movement-related hardware through Arduino-based serial communication. Also supported in the behavioral and neurophysiological data analysis pipelines.

The system was designed to support precise synchronization between behavioral events, movement conditions, and EEG/MEG data acquisition.

## Key Features
- Custom Unity-based desktop virtual environment for neuroscience experiment study
- 2×2 experimental design with movement and optic-flow conditions
- Active and passive movement condition implementation
- Arduino-based external hardware integration
- Real-time serial communication between hardware and Unity
- Behavioral event logging for memory encoding and retrieval tasks
- Support for synchronized EEG/MEG recording
- MATLAB-based behavioral and neurophysiological data analysis support

## Technical Work
- Unity - Game Development Engine
- C# scripting
- Arduino Hardware + Unity scene integration
- MATLAB
- EEG/MEG experimental setup + Behavioral Data Logging

## Research Context
The project explored how movement-related contextual factors affect memory retrieval and neural dynamics. The developed VR framework enabled controlled manipulation of locomotion and visual flow while preserving the experimental precision required for MEG and EEG studies.
